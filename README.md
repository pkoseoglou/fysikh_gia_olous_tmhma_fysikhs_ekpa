# Φυσική για όλους - GitHub Pages

Στατική έκδοση για GitHub Pages. Ανεβάστε **όλα τα περιεχόμενα αυτού του φακέλου** στη ρίζα του repository και ενεργοποιήστε Settings → Pages → Deploy from a branch → main → /(root).

Η δημόσια έκδοση δεν περιλαμβάνει το PHP admin panel. Για αλλαγές άρθρων χρειάζεται νέα δημιουργία των στατικών αρχείων.
