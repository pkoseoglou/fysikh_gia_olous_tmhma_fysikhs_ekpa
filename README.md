# Φυσική για όλους — GitHub Pages

Αυτή είναι στατική έκδοση HTML/CSS/JavaScript για δημοσίευση στο GitHub Pages.

## Δημοσίευση
1. Δημιουργήστε ένα GitHub repository.
2. Ανεβάστε όλα τα περιεχόμενα αυτού του φακέλου (το `index.html` πρέπει να βρίσκεται στη ρίζα).
3. Ανοίξτε **Settings → Pages**.
4. Στο **Build and deployment**, επιλέξτε **Deploy from a branch**, διαλέξτε `main` και `/ (root)`, και πατήστε **Save**.

Η αναζήτηση και τα φίλτρα λειτουργούν χωρίς backend. Κάθε άρθρο έχει δική του στατική σελίδα HTML.

**Σημείωση:** Το GitHub Pages δεν εκτελεί PHP. Η σελίδα διαχείρισης/σύνδεσης και η δυναμική δημοσίευση άρθρων από την αρχική PHP έκδοση δεν περιλαμβάνονται. Για νέο άρθρο, προσθέστε εγγραφή στο HTML ή δημιουργήστε αντίστοιχη σελίδα HTML.
